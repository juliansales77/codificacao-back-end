# 💻 Codificação Back-End

Repositório destinado às atividades, exercícios e conteúdos desenvolvidos durante as aulas de Codificação Back-End.

---

## 📚 Conteúdos das Aulas

### 📖 Aula 01: Revisão do Node.JS e NPM

- Arquitetura do Node.js, Motor V8 e Event Loop.
- Operações de I/O Não-Bloqueantes (Non-blocking I/O).
- Conceitos de Microtasks, Macrotasks, Call Stack e Event Loop.
- Biblioteca libuv e seu funcionamento no Node.js.
- Gerenciamento de pacotes com NPM.
- Estrutura e funcionamento do arquivo package.json.
